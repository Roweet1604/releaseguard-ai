# ReleaseGuard AI — Development Log

## Project Start

ReleaseGuard AI is an AI-powered release intelligence platform.

The goal is to convert natural-language software requirements into executable browser tests, run those tests, collect evidence, analyze failures using AI, and produce an explainable release-readiness report.

## Technology

- React
- Vite
- JavaScript
- Tailwind CSS
- Node.js
- Express
- Playwright
- Amazon Bedrock
- AWS

## Development Approach

The project is being developed incrementally.

Initial focus:
1. Frontend foundation
2. Backend API
3. Requirement analysis
4. Playwright test generation
5. Browser execution
6. Evidence collection
7. AI failure analysis
8. Release readiness
9. AWS deployment
